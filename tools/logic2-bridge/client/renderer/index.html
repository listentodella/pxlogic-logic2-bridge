切换到较旧的 MCU 固件？

下次启动 Bridge 时会重写 PXLogic 的 MCU 固件并让设备重新枚举。该操作无法从 Bridge 内部撤销，只能通过再次切换版本重写。请勿在采集进行中或设备供电不稳时切换。

需要先关闭正在运行的 Logic 2

运行中的 Logic 2 无法挂接到新的 Bridge 会话。它重连后不会在新的 GraphServer 里重建设备状态， 窗口看起来正常但点击采集不会有任何反应，因此必须关闭后重新打开。

该窗口里未保存的采集数据将会丢失。如果有需要保留的测试数据，请先取消， 在 Logic 2 里保存后再回来启动。

第 1 / 4 步

Logic 2 与 Bridge 各管什么

Bridge 把 PXLogic 伪装成 Logic Pro 16，再把采到的数据实时注入未经修改的 Logic 2。两边分工是固定的，弄清这一点后面的设置就都好理解了。

Logic 2 决定
启用哪些通道、采样率、触发条件、滤波、协议解码器，以及开始与停止
Bridge 决定
用哪台 PXLogic、MCU 固件版本、硬件电压判断阈值

因此在 Logic 2 里看到的会话设备名会是 Demo Logic Pro 16，那是 Bridge 的伪装； 真实数据来自你的 PXLogic。

选择 Logic 2 安装

Bridge 需要一份官方 Logic 2，并且会离线判断它的 GraphServer 能否安全注入。 正式支持可直接使用；实验验证可用但需你承担风险；不可用则必须换一个安装。

确认设备与固件

Bridge 随包携带 PXView 1.4.5 起的四个 MCU 固件镜像，默认始终是最新那个， 不需要改动。只有在需要复现旧版本行为时才切换。

检测到的设备 尚未检测 MCU 固件 --

切换到较旧的固件会在下次启动时改写设备的 MCU 闪存并让它重新枚举， 这个操作无法从 Bridge 内部撤销，所以降级需要单独确认。

设置电压判断阈值

这是 PXLogic 硬件比较器的判定电平，高于它记为 1，低于记为 0。它必须按实际探头、 目标和信号质量来选，仅凭目标的标称逻辑电平推不出可靠阈值。
